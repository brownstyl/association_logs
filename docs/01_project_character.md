# MeetingRecord — Project Charter

> Working Title: MeetingRecord (Association Management System)

## Mission

Replace the traditional paper meeting books used by Nigerian associations with a secure, scalable web-based system while serving as a complete full-stack engineering project built from first principles.

---

# Product Vision

MeetingRecord combines the responsibilities of:

- Attendance Register
- Meeting Record Book
- Member Directory
- Contribution Ledger
- Approval Workflow
- Future Communication System

---

# Core Architecture

> Users own identities. Associations own workspaces. Membership connects them.

This means:

- One person has one permanent account.
- One person can belong to multiple associations.
- Each association is isolated from every other association.
- Future roles (Chairman, Treasurer, etc.) exist inside associations.
